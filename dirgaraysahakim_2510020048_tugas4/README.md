# Tugas 4 — Blog Saya

Mata Kuliah: Pemrograman Web 1  
Materi: Pertemuan 4 — CSS Dasar: Sintaks, Selector, Warna & Tipografi

## File
- `index.html` — halaman artikel Blog Saya.
- `style.css` — external stylesheet untuk seluruh tampilan.

## Fitur dan ketentuan tugas
- HTML semantik: header, nav, main, article, time, footer.
- Artikel berisi lebih dari 5 paragraf, 1 blockquote, list, dan 3 tautan eksternal.
- Selector: elemen, class, id, descendant, child (`>`), pseudo-class (`:hover`, `:first-child`), dan grouping.
- Palet warna HEX konsisten.
- Google Fonts: Inter dan Poppins, dengan fallback.
- Lebar konten maksimal 720px dan margin otomatis.
- Komentar CSS ditambahkan pada setiap bagian styling.

## Cara menjalankan
Buka `index.html` melalui browser. Koneksi internet diperlukan untuk memuat Google Fonts.

## Pengumpulan
Upload `index.html`, `style.css`, screenshot tampilan akhir, dan ZIP proyek ke repository GitHub tugas.
